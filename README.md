# Shree Nath Mahato | Portfolio

A static React portfolio for data analyst and data scientist Shree Nath Mahato. Built with Vite, React, and CSS. The dimensional hero sculpture is made with CSS, so the site does not need a WebGL service or runtime API. Home, About, Projects, and Certifications are separate static entry pages.

## Run locally

Requirements: Node.js 20 or newer.

```sh
npm install
npm run dev
```

Create an optimized static build with `npm run build`. The generated site is written to `dist/` and can be hosted on GitHub Pages, Netlify, Vercel, or any static web host. Each page can be opened directly at `index.html`, `about.html`, `projects.html`, or `certifications.html`.

## Project image placeholders

Each project card includes a framed image placeholder. To add a project image, place the image in `public/projects/`, then add an `image` path to that project's entry in `src/main.jsx` and render it in `ProjectCard`.

## Projects

The six featured project links point to the public repositories in the [ShreeNathX GitHub account](https://github.com/ShreeNathX).
